How it works

Normal-approximation formulas, the same ones implemented (and unit-tested against statsmodels and Monte Carlo simulation) in the Python package behind this page:

n_control = (Var_c + Var_t / r) · (z₁₋α/₂ + z_power)² / Δ²          r = n_treat / n_control
Var (proportion) = p(1−p)     Var (mean) = σ²
CUPED:  Var → Var · (1 − ρ²)  ⇒  sample size shrinks by a factor of (1 − ρ²)
  • Several variants: every treatment is compared against the same control. Bonferroni divides α by the number of variants, which is conservative but simple. Total traffic = control + variants × treatment-arm size.
  • CUPED only helps if the pre-experiment metric really is correlated with the outcome; ρ = 0.5 saves 25%, ρ = 0.8 saves 64%. See the case study for a dataset where it saves almost nothing.
  • Limits: for very small samples or rates near 0/1 an exact test is more accurate; it also assumes a fixed horizon (no peeking) and independent users.
